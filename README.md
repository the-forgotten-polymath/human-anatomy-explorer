# Human Anatomy Explorer 🫀

An interactive 3D human anatomy exploration and visualization web platform built with Next.js, React 19, Three.js, GSAP, and Tailwind CSS.

## Features

- 🌐 **Interactive 3D Visualization**: Real-time rendering and rotation of anatomical organs using Three.js and WebGL.
- ✨ **Fluid Micro-animations**: Smooth camera transitions and organ focus animations powered by GSAP.
- 🩺 **Detailed Organ Inspection**: In-depth anatomical insights, physiological functions, and system classifications.
- 🌍 **Multi-language Support**: Comprehensive internationalization (i18n) setup.
- ⚡ **Modern Stack**: Built with React 19, Next.js, Tailwind CSS v4, and Lucide Icons.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) / React 19
- **3D Engine**: [Three.js](https://threejs.org/)
- **Animations**: [GSAP](https://greensock.com/gsap/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Database & ORM**: Drizzle ORM

## Getting Started

### Prerequisites

- Node.js `>=22.13.0`
- npm, pnpm, or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/the-forgotten-polymath/human-anatomy-explorer.git
   cd human-anatomy-explorer
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to explore the 3D human anatomy.

## Build & Testing

```bash
# Build production bundle
npm run build

# Run linting
npm run lint

# Run test suite
npm test
```
